# SkyNest Co-Living Spaces

## Project Description
SkyNest Co-Living Spaces is an accommodation website designed to provide flexible and comfortable living solutions for individuals, students, professionals and corporate clients. The website allows visitors to explore accommodation options, discover available facilities and contact the SkyNest team for enquiries.

## Website Features
- Home page with an introduction to SkyNest.
- About section providing information about the company.
- Accommodation options for short-term and long-term stays.
- Corporate accommodation bookings.
- Custom accommodation packages.
- Facilities and services information.
- Testimonials from customers.
- Contact section with an enquiry form.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Website Design
The website uses a responsive layout to support different screen sizes, including desktops, tablets and mobile phones.

## Project Purpose
This project was developed as part of the Pearson BTEC International Level 3 IT Website Development assignment. Its purpose is to demonstrate website design, development, functionality and usability.
